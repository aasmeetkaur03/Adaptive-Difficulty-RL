# Adaptive Difficulty Using Reinforcement Learning

Research project implementing RL-based Dynamic Difficulty Adjustment (DDA).
- Custom Gymnasium environment simulating player-game interaction
- PPO agent adjusting difficulty to maintain target win rate and engagement
- Baselines: static difficulties and rule-based DDA
- Evaluation: simulated players of varying skill

Code : Google Colab notebooks + Python package
Paper: Short paper targeting FDG late-breaking / PCG workshop + arXiv preprint
